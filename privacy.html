プライバシーポリシー

最終更新日：2026年11月18日

karada-log（以下「本ツール」）は、作者本人のみが自分のデータを扱うために使う個人用ツールです。

取得するデータ

本ツールは、作者本人の Google アカウントの許可のもと、Google Health API から睡眠・活動・心拍・体重などの健康データと食事記録を読み取り、作者本人が記録した食事を Google Health に書き込みます。

データの使い方と保存先

  • データは作者本人の健康状態を本人が把握するためだけに使います。
  • データは作者本人が管理する非公開のリポジトリにのみ保存します。
  • データを第三者に販売・提供・共有することはありません。広告には使いません。

Google API Services User Data Policy

本ツールによる Google API から受け取った情報の利用は、Limited Use の要件を含む Google API Services User Data Policy に従います。

削除

アクセスは Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。保存したデータは作者本人がリポジトリから削除できます。
